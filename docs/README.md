# docs/

`privacy-policy.html` is the public privacy policy for the Play Store listing.
Before publishing, replace `SUPPORT_EMAIL_HERE` with your support email.

Host it free with GitHub Pages: repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/docs`.
The URL becomes `https://sharykafigma.github.io/bazaar-flow/privacy-policy.html`.
(GitHub Pages on a free account needs a public repo. If you keep the repo private, paste the same text into a free Google Sites page instead.)
